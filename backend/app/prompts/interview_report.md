## 评分要求

1. 只依据上面的问答记录评分。**不得**臆测候选人没答的内容，也不要把资料里没有的信息写进报告。
2. 四个维度各 0-100 分，并给一句具体依据（引用候选人回答里的原话或事实）：
   - `专业能力`：回答是否准确、有细节、有取舍理由；
   - `表达与结构`：是否先结论后细节、层次清楚；
   - `岗位匹配度`：回答内容与目标岗位要求的贴合程度；
   - `应变与深度`：面对追问是否稳、是否会主动补充数据或反思。
3. `score` 是总分（0-100），按四个维度加权取整，不要与维度分明显矛盾。
4. `strengths` 写 2-4 条**具体**优点；`improvements` 写 2-4 条**可执行**的改进建议（例如"把项目里的'优化了性能'改成'把 P99 从 1.2 秒降到 220 毫秒'"）。
5. `summary` 用 100 字以内的总评，语气像一个真实的面试官给候选人的反馈：客观、具体、可执行。
6. 如果候选人多处回答"不知道"或明显没准备，要如实反映在分数与建议里，不要为了好听说空话。

只输出一个 JSON 对象，不要任何解释或 Markdown 代码块标记：
